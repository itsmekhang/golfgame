# Selected wedge redesign

Installed from `Wedge_Redesign_Pack` for all 11 wedge catalog entries:

`loaner_pw`, `loaner_gw`, `loaner_sw`, `loaner_lw`, `grocery_pw`, `bent_neck_pw`, `rusty_gap_52`, `flop_master_60`, `raw_face_56`, `tour_grind_58`, and `sand_shovel`.

Each head is attached to the existing catalog shaft and grip through the supplied hosel socket. The embedded base-color, ORM, and normal maps are preserved, while the game's condition shader continues to apply wear. Godot remaps the material's selected glTF texture coordinates into the primary imported UV channel; the condition shader uses that channel too. Forcing UV2 after import sampled empty atlas regions and made every wedge black.

Shop thumbnails show the grooved face and top, using the same runtime skins with transparent backgrounds and cast shadows. They are generated by `tools/render_shop_thumbnails.gd`. The existing `shop_thumbnails/512/` path and `_base_back.png` filenames are retained for compatibility; regenerated images are 640 x 560 pixels.
