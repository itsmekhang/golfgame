## Integration

`OFGEquipmentAssets.head_scene_for_asset()` first checks `skins/<asset_id>_base.glb`; if a per-item skin exists it takes priority over the shared family scene. `Driver_Head.glb`, `Fairway_Wood_Head.glb` and `Hybrid_Rescue_Head.glb` remain the fallback for any catalog id without its own skin (currently none — all 18 driver/fairway/hybrid entries have a skin).

All heads (family scenes and per-item skins alike) are authored in meters with a `ShaftSocket` marker at their origin. The adapter aligns the marker position and its +Y axis with the original shaft, keeping unit scale and every supplied component transform. It removes the old head and ferrule, retains the original shaft and grip, and marks every new component as a head for camera fitting and wear.

The wear materials preserve the supplied albedo, normal, roughness and metallic maps, their factors and texture channels, clearcoat, and double-sided rendering. Wear state remains private to each club instance. Club prices, statistics, and shot behavior continue to come from the existing catalog.

The 18 images in `previews/` override the old clubhouse and HUD thumbnails; they are the pre-rendered per-item skin thumbnails described above rather than being generated by `tools/render_selected_club_previews.gd`. That tool still exists for regenerating Inspect-UI-style captures (e.g. worn/underside review shots) but is no longer the source of the shop-facing previews.

## Verification and regeneration

- `tests/selected_head_swap_test_base.gd`: the shared checks (source mesh identity, attachment alignment, unchanged shafts/grips, PBR maps, independent wear, replacement thumbnails) parameterized by family, resolving each catalog item's head and thumbnail through `Equipment.head_scene_for_asset()`/`EquipmentPreview.get_texture()` per item, so it validates each of the 18 per-item skins individually rather than just the shared family scene.
- `tests/driver_head_swap_test.gd`, `tests/fairway_head_swap_test.gd`, `tests/hybrid_head_swap_test.gd`: thin per-family wrappers over the shared base, covering all eight drivers, seven woods and three hybrids.
- `tools/render_selected_club_previews.gd`: actual Inspect UI captures, plus worn and underside views, using private unsaved game state. No longer the source of the shop-facing `previews/` thumbnails (see above), but still useful for ad hoc review renders.

Run with Godot 4.7.2 from the project root:

```text
godot --headless --editor --import --quit
godot --path . --script tools/render_selected_club_previews.gd
godot --headless --editor --import --quit
godot --headless --path . --script tests/driver_head_swap_test.gd
godot --headless --path . --script tests/fairway_head_swap_test.gd
godot --headless --path . --script tests/hybrid_head_swap_test.gd
```

The capture tool requires a real rendering backend. Review screenshots go to `build/selected_heads_review/`. The headless regression tests can emit Godot dummy-renderer material teardown messages; their assertions and the GPU capture run are checked separately.
